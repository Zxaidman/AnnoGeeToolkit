AnonGee Toolkit 0.1.0

SUPPORTED ENVIRONMENT

• Windows 10/11 x64
• Autodesk Revit 2025
• pyRevit 6.1.x–6.3.x or 6.5.0–6.5.5 are accepted without warning
• pyRevit 6.4.x is not supported
• Newer unvalidated pyRevit 6.x may be allowed with a warning
• pyRevit 7.x and later are not currently supported
• Standalone Python is not required

PYREVIT PREREQUISITE

AnonGee Setup milestone 0.4.0 includes the official signed per-user
pyRevit 6.5.5 installer as a prerequisite.

• If pyRevit is not installed, Setup installs pyRevit 6.5.5 automatically.
• During prerequisite installation, the pyRevit progress window remains
  visible so the user can see that Setup is actively working.
• If an incompatible per-user pyRevit version is detected, Setup asks for
  explicit permission before replacing/upgrading it with pyRevit 6.5.5.
• Choosing Yes starts the pyRevit 6.5.5 repair and then continues AnonGee
  installation after the prerequisite is verified.
• Choosing No closes AnonGee Setup without installing AnonGee.
• Existing compatible pyRevit installations are left unchanged.
• Newer unvalidated pyRevit 6.x installations are not downgraded.
• An incompatible all-users pyRevit installation is not modified by this
  per-user Setup. Ask your BIM/IT administrator to update it, then run Setup
  again.
• If AnonGee Setup itself is run silently, an incompatible existing per-user
  pyRevit is not modified because explicit repair consent cannot be obtained.

pyRevit is a separate third-party project and remains subject to its own
GPLv3 license and notices. AnonGee Toolkit's proprietary EULA does not replace
or restrict pyRevit's license rights.

INSTALLATION LOCATIONS

AnonGee Toolkit installs its pyRevit extension into:
%APPDATA%\pyRevit\Extensions\AnonGee.extension

Installer-owned support files are stored under:
%LOCALAPPDATA%\Zxaidman\AnonGee\BIM-Toolkit

Roaming AnonGee Toolkit settings are stored under:
%APPDATA%\Zxaidman\AnonGee\BIM-Toolkit

Please close Autodesk Revit before continuing.
