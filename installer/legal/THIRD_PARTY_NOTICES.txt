PYREVIT
=======

pyRevit is a separate third-party framework and prerequisite used to host the
current AnonGee Toolkit extension. pyRevit is not owned by Zxaidman and is
licensed under its own terms, including GNU GPL version 3 for the pyRevit
project.

Installer milestone 0.4.0 embeds the official signed per-user pyRevit
6.5.5.26237 installer as an unmodified prerequisite build input. AnonGee Setup
may run that installer automatically when pyRevit is missing or when a safely
repairable incompatible per-user pyRevit installation is detected.

AnonGee's proprietary EULA applies only to AnonGee-owned software. It does not
replace, narrow, or override rights granted directly by pyRevit's GPLv3
license. Uninstalling AnonGee does not uninstall pyRevit because pyRevit is an
independent prerequisite and may be used by other Revit extensions.

Before any public or commercial distribution of an AnonGee Setup executable
that embeds pyRevit, the release process must also preserve the applicable
pyRevit GPLv3 license/notices and satisfy the GPLv3 corresponding-source
obligations for the exact pyRevit binary being redistributed. Do not rely on
AnonGee's proprietary source repository as a substitute for pyRevit's own
license and source obligations.

RELEASE CHECKLIST
=================

Before each production release:

1. Compare this inventory with tools/requirements.txt.
2. Confirm the packaged versions match the pinned requirements.
3. Preserve upstream LICENSE/COPYING/NOTICE files present in wheel metadata.
4. Review native-library notices for NumPy, Shapely, pywin32, and any newly
   added binary dependencies.
5. If pyRevit or another GPL-covered prerequisite is bundled, preserve its
   license/notices and satisfy the corresponding-source obligations for the
   exact redistributed binary.
6. Re-review xlwings usage to confirm no PRO-only feature is being packaged or
   relied upon without the appropriate license.

This notice is an engineering license inventory, not a substitute for legal
review before large-scale commercial distribution.
